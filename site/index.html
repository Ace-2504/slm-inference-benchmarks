Speculative decoding, live

Qwen2.5-7B-Instruct on one NVIDIA L4, generating the same answer two ways. First plain: the 7B alone, one token per forward pass. Then speculative: the small Qwen2.5-0.5B drafts k tokens ahead and the 7B verifies them in a single pass. Both are greedy, so the answer is the same; only the speed differs. As the speculative run streams, each token is coloured by who produced it. Try the code preset and then the creative one — the mechanism is identical, the payoff is not.

Continuous batching & PagedAttention

Held offline — sustained multi-request GPU load isn't reasonable to serve to a visitor — but measured the same way. Plots and numbers are in the report and repo.

How it runs

Experiment 1 uses a 125M-class model; experiment 2 pairs a 7B target with a 0.5B draft, all bf16 on an L4 via Modal. Every timer synchronises, warms up and repeats — validated by an 8-test gauntlet showing an un-synchronised matmul under-reports its time by ~330×. Both sides are checked for identical tokens first.
